Приватность

Какие данные хранит проект и кто их видит

Карта Породы Статистика Источники Приватность Аккаунт

Кратко

Смотреть карту, паспорта деревьев и статистику можно без регистрации. Счётчиков посещений и рекламы на сайте нет, но, как у любого сайта в интернете, сервисы, на которых он работает, видят адрес подключения (IP) и сведения о браузере каждого посетителя и записывают их в свои технические журналы: GitHub Pages (файлы сайта), Supabase (онлайн-база) и OpenStreetMap (подложка карты).

Аккаунт нужен только руководителю команды, которая осматривает деревья. Для него хранятся email и пароль руководителя, название команды и, по желанию, школа, а при каждом входе система входа Supabase Auth сама записывает технические сведения: адрес подключения (IP), браузер и время входа. Имён, фамилий, телефонов, адресов и фотографий людей не храним.

Что мы храним

  • Email и пароль руководителя команды — только в системе входа Supabase Auth; пароль хранится в виде хэша (его не видит никто, включая координатора). Email публично не показывается и не выдаётся через открытый интерфейс базы.
  • Технические сведения о входах — при входе руководителя Supabase Auth сохраняет адрес подключения (IP), сведения о браузере и устройстве (user-agent) и время входа: в сеансах входа и в журнале входов проекта. Их видит только координатор в панели управления Supabase; на сайте они не показываются никому.
  • Журналы сервисов — при открытии любой страницы GitHub Pages и Supabase, как любые серверы в интернете, записывают адрес подключения (IP), браузер и время запроса в свои технические журналы; подложку карты так же видят серверы OpenStreetMap. Журналы Supabase координатор может посмотреть в панели управления, журналы GitHub и OpenStreetMap проекту недоступны.
  • Название команды и школа — школа необязательна.
  • Осмотры деревьев: номер дерева, дата, состояние, полив, заметка и то, какая команда сделала запись. Координаты места осмотра не сохраняются. Для нового или ещё не отмеченного на карте дерева команда может прислать его координаты — это место дерева, а не человека.
  • Фотографии деревьев — без лиц людей; при загрузке с фото удаляются служебные сведения (в том числе координаты съёмки).
  • Код заявки команды и версия и дата согласия — чтобы модератор подтвердил команду и было видно, с каким текстом согласился руководитель.
  • На вашем устройстве браузер хранит ключ входа (сеанс), пока вы не нажмёте «Выйти на этом устройстве»; записи полевого режима хранятся на устройстве до выгрузки.

Не храним: фамилии и имена (в том числе детей), телефоны, адреса, даты рождения, фотографии людей. Поэтому в названии команды не пишите имена — например, «Юные экологи 8Б».

Зачем

  • Email и пароль — чтобы руководитель входил в аккаунт команды и только он отправлял её записи.
  • Технические сведения о входах и журналы — их ведут сами Supabase и GitHub для работы и защиты сервиса; проекту они нужны только чтобы разобраться, если кто-то вошёл в аккаунт команды без спроса.
  • Название команды — чтобы на карте было видно, кто осматривает и опекает дерево.
  • Школа — по желанию команды, для признания её работы.
  • Осмотры и фото — чтобы следить за состоянием посаженных деревьев.
  • Код заявки — чтобы на сайте не появилась команда «от чужого имени»: модератор подтверждает команду только по коду, который руководитель сообщил лично.

Кто что видит

  • Все посетители (публично): деревья, осмотры (кроме скрытых модератором) и проверенные модератором фото; название подтверждённой команды и её школа, если указана; какая команда опекает дерево. Email руководителя публично не виден никогда.
  • Сама команда (руководитель после входа): всё своё — статус команды, код заявки, свои осмотры и фото, в том числе ещё не проверенные фото и скрытые модератором осмотры.
  • Модератор и администратор проекта: все команды (название, школа, статус), все осмотры и фото, в том числе неподтверждённые и скрытые, — чтобы проверять их. Email руководителей и технические сведения о входах (IP, браузер, время) в интерфейсе сайта им не показываются; их видит только координатор — владелец проекта в панели управления Supabase.

Где хранится

Данные хранит облачная платформа Supabase; сервер базы — во Франкфурте (Германия), то есть за пределами Республики Казахстан. Файлы сайта размещены на GitHub Pages. Подложка карты загружается с серверов OpenStreetMap — как у любой онлайн-карты, они видят адрес вашего подключения. GitHub и OpenStreetMap — тоже зарубежные сервисы: их технические журналы (IP, браузер, время) хранятся за пределами Республики Казахстан.

Срок хранения и удаление

Данные хранятся, пока идёт проект. Руководитель команды может в любой момент попросить удалить данные команды — удаляем не позже чем через 30 дней после запроса.

Удаляются: аккаунт (email и пароль) вместе с его сеансами входа, команда (название и школа), код заявки и отметка о согласии, предложения новых деревьев и заявки на опеку деревьев (вместе с командой), фотографии команды — записи о них удаляются вместе с командой, а сами файлы фото координатор удаляет из хранилища вручную. Осмотры команды удаляются или, если вы согласны их оставить для истории дерева, остаются без названия команды. Удаляем и из собственных выгрузок проекта. Журнал входов проекта и технические журналы сервисов (Supabase, GitHub Pages, OpenStreetMap) ведут сами эти сервисы: при удалении аккаунта записи журналов сами не стираются и хранятся по правилам сервисов.

Запрос на удаление или вопрос о данных: лично координатору проекта в школе.
